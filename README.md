# My Scents Collection

A personal fragrance collection tracker for organizing, rating, and discovering scents in your perfume collection.

## Overview

My Scents Collection helps fragrance lovers keep track of every bottle they own, want to try, or have finished. It makes it easy to catalog perfumes, note their characteristics, and review your favorites.

## Features

- Add and manage fragrance entries
- Track brand, fragrance family, notes, and concentration
- Save ratings and personal reviews
- Mark favorites and wishlist items
- Filter and search your collection
- Keep track of what you own, want, and have worn
- Simple and clean interface for quick browsing

## Why this project?

Perfume collections can grow quickly, and it becomes hard to remember what you own, what you liked, and what you want to try next. This project provides a lightweight way to organize all of that in one place.

## Tech Stack

This project can be built with modern web technologies such as:

- HTML / CSS / JavaScript
- React or another front-end framework
- Local storage or a backend database for persistence

## Getting Started

1. Clone the repository
2. Install dependencies
3. Start the app locally

Example:

```bash
npm install
npm run dev
```

## Usage

- Add a new scent to your collection
- Enter the name, brand, notes, and rating
- Organize items by category or favorite status
- Review your collection to decide what to wear next

## Project Goals

- Keep your perfume collection organized
- Make fragrance reviews easy to track
- Build a useful personal tool for collectors and enthusiasts
